# ASR Tech Solutions

A responsive React, Vite, and Tailwind CSS recreation of the ASR Tech Solutions landing page. Responsive layout, spacing, typography, and interaction styles are implemented with Tailwind utilities; `src/index.css` contains only base document styles.

## Run locally

```bash
npm install
npm run dev
```

## Verify and build

```bash
npm run lint
npm run build
```

## Page components

`src/pages/Home.tsx` composes the reusable `Navbar`, `Hero`, `Services`, `InternshipBanner`, `About`, `Footer`, and `ScrollReveal` components. `Logo` and `Icon` provide the shared vector marks and icon set.

Local page imagery is stored in `public/assets/`.
